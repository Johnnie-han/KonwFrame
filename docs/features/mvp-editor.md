# 第一版编辑器功能规格

版本：0.1；日期：2026-11-03。所属范围：视频制作闭环。状态：规格已编写，功能未实现。

## 目标与依赖

让用户在浏览器中手动制作、保存和导出一条知识科普视频。依赖已定义的 [需求编号](../01-product-requirements.md)、[数据模型](../04-data-model.md) 和 [接口契约](../05-api-contracts.md)。实现时核查 Remotion skills、依赖版本和实际渲染环境。

## 范围

包括 F01—F10；不包含 AI、自动节拍、复杂拖拽、自动保存、跨项目素材复用、完整撤销历史。首版仅一段全片音乐及每镜一段配音，不暴露通用多轨编辑。

## 数据与交互

编辑器的选择对象、播放位置、面板开关是 UI 状态；不写入 ProjectDocument。文案、顺序、图片和音频绑定、时长及音量是项目内容；变动时标记 dirty。

手动保存期间继续编辑时，只将已提交的那份本地文档标记为已保存；如果已有新修改，保存完成后仍显示未保存。未保存数据在网络失败后仍留在页面内存，不承诺刷新恢复。

当用户点击“保存并导出”，导出必须对应刚保存成功的明确 revision。如果保存后服务端再次变化，导出返回冲突，界面说明原因，不能悄悄渲染另一个版本。

文件上传和保存为两个状态：上传素材可已持久化，但新绑定尚未保存。提示需分别描述。首版未引用素材不自动永久删除。

## 验收方法

使用 [T01—T16](../07-test-and-acceptance.md) 逐项记录结果。测试使用可上传的 PNG、WAV 及真实讲解录音，不只依赖空音频或模拟任务。视觉检查应覆盖三类模板、长中文、字体、空图和竖屏安全边距。
