# 项目概述

版本：0.1；日期：2026-11-03。本文是设计基线，功能尚未实现。

## 项目名称

中文名：知帧；英文名：KnowFrame；实际远端：[Johnnie-han/KonwFrame](https://github.com/Johnnie-han/KonwFrame)，保留用户创建的仓库拼写。

“知”代表知识拆解与讲解，“帧”代表分镜、动效和视频制作。产品表达为“让知识按节奏成片”。本地目录暂保留原名，避免影响已有文档和脚本路径。

交付时需要保留真实的小步开发提交历史，让评委在 GitHub 上看到从设计到功能实现的持续进展。提交与同步规则统一维护在项目根目录 AGENTS.md。

## 用户与问题

面向独立知识创作者、教师及科普内容运营者。用户有一段讲解内容，希望用清晰的文字、图解、配音和少量动效制成短视频，并重复使用已有素材。

初期假设：一个操作者、一个受控工作空间、桌面浏览器编辑。服务器部署后从浏览器访问，项目及素材保存在服务端。多人协作、公开注册和移动端编辑不在首版范围。

## 产品承诺

用户可以把手动整理的分镜制作成一条约 60 秒的竖屏科普视频；修改后可预览、保存、重新打开，并获得可下载的 MP4。智能拆解、卡点与效果建议沿用同一个项目模型逐步加入。

第一版成功标准：使用样例完成制作、保存恢复和一次真实导出，预览与导出内容、时序一致。这里是未来验收目标，不表示已经通过。

## 首版约定

| 项目 | 约定 |
| --- | --- |
| 输出 | 1080 × 1920，30fps，MP4 / H.264 / AAC |
| 画面 | 标题、知识点、总结三类模板，文字和可选图片 |
| 时长 | 默认目标 60 秒；单镜头至少 1 秒，项目最多 180 秒 |
| 分镜 | 手动增删、排序、文案和时长编辑 |
| 音频 | 每分镜可关联一段配音，全片可关联一段背景音乐 |
| 保存 | 手动保存；服务器保存为准，明确提示未保存修改 |
| 访问 | 本地开发；部署时先为单一工作空间配置受控访问 |
| 客户端 | 先验收桌面 Chrome / Edge；具体版本在阶段 1 记录 |

## 设计原则

- 讲解完整性优先于节拍；先让人看懂和听清，再增加效果。
- 预览与导出共享确定性视频组件和项目数据。
- 操作结果可观察；失败可恢复；不覆盖用户未保存的编辑。
- 素材、导出和数据库独立持久化，应用重启不丢数据。
- AI 返回可校验的草稿和参数，用户保留编辑权。
