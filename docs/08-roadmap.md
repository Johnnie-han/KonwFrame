# 阶段开发计划与进度

## 维护规则

- 在本文件填写具体阶段内容，不在 AGENTS.md 中重复维护。
- 状态统一使用：未开始、进行中、待验收、已完成、受阻。
- 只有阶段交付和验收均完成后，才能勾选完成项并标记“已完成”。
- 完成时同步记录完成日期、验收证据及遗留问题，并更新开发日志。
- 调整阶段范围时记录原因，不静默删除未完成工作。

- 遗留事项：真实配音、依赖锁定、运行验收属于后续实现；服务器规格在部署前落实，不表示相关功能已完成。

- 一套贯穿开发全过程的样例文稿和素材。
- 第一版功能清单与后续功能清单。

验收：
- 第一版范围明确。
- 每个功能有输入、输出和验收标准。

### 阶段 1：视频制作闭环

实现：
- 新建项目。
- 手动添加、编辑、删除和排序分镜。
- 编辑画面文字。
- 上传图片、配音和背景音乐。
- 选择基础画面模板。
- 设置分镜时长。
- 视频预览。
- 保存和重新打开项目。
- 导出 MP4。
- 显示导出进度、失败原因及重试入口。

验收：
- 使用真实素材制作一条约 60 秒的科普视频。
- 保存后重新打开，编辑内容保持一致。
- 导出文件可播放。
- 预览和导出的内容、时序保持一致。

### 阶段 2：知识拆解与分镜辅助

实现：
- 输入主题、文稿或参考资料。
- 设置受众、目标时长和讲解深度。
- 生成知识结构与分镜草稿。
- 编辑、拆分、合并及局部重新生成分镜。
- 记录参考来源和待核实内容。

验收：
- 生成结果可编辑，并可直接进入预览和导出流程。
- 不覆盖用户已经修改的内容。
- 智能服务失败时，手动制作仍然可用。

### 阶段 3：素材库与动效微调

实现：
- 保存、分类、搜索和预览素材。
- 保存音乐和音效。
- 提供基础动效模板。
- 调整位置、缩放、透明度、颜色和动画时长。
- 保存并复用动效预设。
- 撤销、重做和自动保存。

验收：
- 动效参数修改后可预览。
- 保存的预设可在重新打开项目后复用。
- 撤销和重做能恢复正确的项目状态。

### 阶段 4：节拍分析与转场卡点

实现：
- 音乐波形。
- 节拍候选点与置信度。
- 节拍点手动修正。
- 时间轴节拍吸附。
- 转场对齐建议。
- 分镜锁定。

验收：
- 使用不同节奏类型的音乐验证。
- 用户能够试听并修正分析结果。
- 应用卡点后不截断配音。
- 不产生意外空隙、重叠或时长变化。

### 阶段 5：动作音效匹配

实现：
- 为动效定义语义事件。
- 根据事件匹配已有音效。
- 支持试听、替换、静音和移动音效。
- 调整音量、时间偏移及淡入淡出。
- 后续再接入音效生成服务。

验收：
- 音效随对应动作移动。
- 删除动作时正确处理关联音效。
- 重复应用建议不会重复插入音效。
- 配音清晰，音效密度和音量可控。

### 阶段 6：参考音频与效果描述

实现：
- 上传参考音频。
- 输入期望效果描述。
- 分析节奏和能量变化。
- 生成可编辑的效果方案。
- 展示修改范围。
- 支持局部应用和撤销。

验收：
- 建议能映射到已有模板和参数。
- 用户能够理解将发生哪些修改。
- 分析失败时仍可手动编辑。

仅凭音频不能确定参考案例的视觉效果。
视觉推荐应结合用户描述和已有模板；
如需分析参考画面，另行规划参考视频功能。
