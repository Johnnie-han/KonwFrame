# 产品需求

版本：0.1；日期：2026-11-03。状态：需求基线已编写，以下功能均未实现。

## 第一版必须交付

功能编号用于接口、规格和验收之间的追踪。详细状态与边界见 [第一版功能规格](features/mvp-editor.md)。

| 编号 | 功能 | 输入 | 输出 | 可观察验收标准 |
| --- | --- | --- | --- | --- |
| F01 | 新建及打开项目 | 名称，或现有项目 ID | 固定画幅的空项目，或已保存项目 | 新项目获得唯一 ID；重新打开恢复服务端最新已保存版本 |
| F02 | 手动分镜 | 新增、删除、前后移动指令 | 顺序稳定的分镜列表 | 增删排序后预览顺序相同；删除前确认；最后一镜删除后进入空态 |
| F03 | 文字编辑 | 标题、画面文字、讲解文案 | 当前分镜内容 | 中文和换行可保存恢复；画面文字即时更新，讲解文案只作配音参考 |
| F04 | 上传及关联素材 | PNG/JPEG 图片；WAV/MP3 配音或音乐 | 项目内素材记录与关联 | 合法文件可预览或试听；不合法文件给出原因，失败不改变既有素材 |
| F05 | 基础模板 | title、knowledge、summary 和可选图片 | 对应模板画面 | 三类模板均可预览和导出；切换模板保留文案及图片引用 |
| F06 | 时长与音频设置 | 分镜秒数、分镜配音、全片音乐及音量 | 整数帧时间轴与音频片段 | 总时长准确；配音超长时拒绝应用并提供延长分镜操作，不静默截断 |
| F07 | 视频预览 | 当前本地编辑文档 | 可播放、暂停、定位的视频 | 使用当前未保存编辑；缺失素材可定位，禁止导出；播放需用户手势启动 |
| F08 | 保存及恢复 | 项目文档及基础 revision | 新 revision 和保存时间 | 保存后重开一致；失败仍保留编辑；版本冲突不覆盖服务端数据 |
| F09 | MP4 导出 | 已保存 revision，固定导出规格 | 后台任务和 MP4 下载入口 | 提交返回任务而非阻塞等待；导出期间继续编辑不改变本次快照 |
| F10 | 导出进度与重试 | 任务 ID 或失败任务的重试指令 | 状态、进度、安全错误及新任务 | queued/running/succeeded/failed 均有反馈；失败可按原快照重试 |

F01—F10 构成第一版制作闭环，不包括下文智能能力。阶段推进仅在 [阶段文件](08-roadmap.md) 维护。

## 首版限制与失败规则

- 默认项目名“未命名项目”；名称去除首尾空格后为 1—80 字符。
- 至多 30 个分镜；分镜整数帧长度至少 30，总长至多 5400 帧；空项目可保存，不能导出。
- 标题最多 40 字符，画面正文最多 160，讲解文案最多 1000；画面仍需检查视觉溢出。
- 图片不超过 20 MiB，音频不超过 100 MiB；具体像素、采样率和时长在服务端探测，不信任扩展名。
- 首版图片输入仅 PNG/JPEG，不接收用户上传的 SVG 或可执行内容。内置 SVG 图解可作为受信任源文件，样例同时提供可上传 PNG。
- 音频不自动循环；短于场景/全片的部分为静音；长背景音乐在片尾截断并淡出。
- 分镜配音长于分镜时显示所需时长，用户选择延长；超过项目上限时拒绝。
- 未保存修改在离开或刷新前提示。自动保存和完整编辑撤销历史留待后续；首版不承诺断电恢复未保存内容。
- 素材上传只进入所属项目；服务器不以客户端提供的本地路径或远程 URL 作为导出输入。

## 后续能力边界

| 编号 | 能力 | 输入 → 输出 | 验收方向 |
| --- | --- | --- | --- |
| L01 | 知识拆解 | 主题/文稿/资料 → 带知识点及来源状态的草稿分镜 | 可编辑、局部重生成，不覆盖用户修改；失败可手动制作 |
| L02 | 动效与素材复用 | 模板参数和素材 → 可搜索、可跨分镜复用的预设 | 重开后仍可复用，参数可微调，撤销重做准确 |
| L03 | 节拍与卡点 | 音乐和锁定约束 → 可修正节拍点及转场建议 | 试听修正有效，不截断配音，不产生时间轴空洞 |
| L04 | 动作音效 | 动效语义事件 → 音效片段绑定 | 跟随动作、无重复插入、音量可控；生成服务另行接入 |
| L05 | 参考音频描述 | 音频和文字描述 → 可解释、可局部应用的方案 | 显示影响范围，可撤销，分析失败可手动编辑 |

## 服务器交付约束

最终需要受控访问、服务端存储、独立渲染任务、部署配置和备份恢复说明。部署验收不能用本地开发结果替代。首版应用实现与最终上线是不同验收范围，见 [部署清单](10-deployment.md)。

不在当前范围：多人实时协作、完整剪映功能复刻、移动端编辑、任意代码执行、自动生成全部视频素材、支付及公开素材市场。
